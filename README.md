# 廃校おばけ大作戦

3人称視点のオープンワールド・サバイバルホラー（ちょっぴりコメディ）。
プレイヤーは廃校に住みつく**おばけ**。心霊スポット目当てで乗り込んでくる人間たちを、
仕掛けと召喚おばけで驚かせ、校門の外へ追い出すゲーム。

Three.js（ローカルに同梱）＋バニラ JS。ビルド不要、画像・音声ファイルなし
（形状はすべてコード生成、効果音はすべて WebAudio 合成）。

## 遊びかた

```bash
node "I:/Claude code/haikou-obake/serve.js"
```

ブラウザで <http://localhost:5178> を開いて「はじめる」。

| キー | 動作 |
|---|---|
| WASD | 移動 |
| マウス | 視点 |
| Shift | ダッシュ（スタミナ消費） |
| Space / C | 浮く・沈む |
| E | おどかす（背後からは1.75倍） |
| Q | すりぬけ（壁を通る／人間から見えにくくなる） |
| Tab | おばけ工房（仕掛け・おばけの作成） |
| F | 選んだ仕掛けを設置 |
| 1〜6 / ホイール | 仕掛けの選択 |
| Esc | ポーズ |

### スマホ・タブレット（横向き）

| 操作 | 動作 |
|---|---|
| 左下のスティック | 移動（端まで倒すとダッシュ） |
| 画面をなぞる | 視点 |
| 😱 | おどかす |
| 👻 | すりぬけ（押しているあいだ） |
| ⬆ | 浮く |
| 📍 | 選んだ仕掛けを置く |
| 🛠 | おばけ工房 |
| 下のならび | 仕掛けを選ぶ（タップ） |

端末を判定して自動で切り替わります。スマホでは懐中電灯のライトを2本、
解像度・塵・材料の数を落として軽くしています（PCは5本・フル画質）。

材料は近づくと自動で拾える。

## 今できること（第1段階）

- **マップ**: 4階建ての校舎（各階に教室・特別教室・男女トイレ・廊下）＋中庭＋渡り廊下＋部室棟＋運動場＋体育館
  - 東西の階段で全階つながっている
- **人間 AI**: 5種の性格（度胸・移動速度・セリフが別々）。探索 → びくびく → パニック → 逃走 → 脱出
  - ウェイポイント経路探索（91+ノード、視線判定つき）
  - 暗い屋内 / ひとりぼっちだと怖がりやすい
  - 同じ手を繰り返すと**慣れて笑われる**。別の手を続けざまに出すと「たたみかけ」ボーナス
  - 一度植えつけた恐怖は完全には消えない（恐怖の下限が上がる）
- **仕掛け 6種** / **召喚おばけ 3種** / **材料 7種**
- 驚かせると人間が道具・材料を落とす
- 追い出した人数でランクアップ、強いおばけが解放される
- procedural な夜空・月・星・霧・漂う塵、非常灯のライトプール

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | UI（HUD・工房メニュー・タイトル）と CSS |
| `src/main.js` | ゲームループ、入力、ウェーブ管理、作成・驚かし処理 |
| `src/world.js` | 廃校と中庭の生成、部屋の家具、当たり判定・ナビの登録 |
| `src/meshbuild.js` | 静的ジオメトリを1メッシュにまとめるビルダー |
| `src/player.js` | おばけの操作と3人称カメラ |
| `src/human.js` | 人間 AI・恐怖ゲージ・ふきだし |
| `src/entities.js` | 材料・仕掛け・召喚おばけ・浮き文字 |
| `src/util.js` | 数学、AABB 当たり判定、ウェイポイント経路探索 |
| `src/sky.js` | 夜空・星・月 |
| `src/audio.js` | WebAudio による効果音合成 |
| `src/touch.js` | スマホ・タブレットのタッチ操作 |
| `src/data.js` | 材料・仕掛け・おばけ・人間・ランクの定義（**バランス調整はここ**） |
| `serve.js` | ローカル静的サーバ（127.0.0.1 のみ） |
| `devshot.js` | 開発用スクリーンショット保存（`POST /__shot?n=名前`） |
