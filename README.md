# 廃校おばけ大作戦

3人称視点のオープンワールド・サバイバルホラー（ちょっぴりコメディ）。
プレイヤーは廃校に住みつく**おばけ**。心霊スポット目当てで乗り込んでくる人間たちを、
仕掛けと召喚おばけで驚かせ、校門の外へ追い出すゲーム。

**▶ あそぶ: <https://haikou-obake-daisakusen.vercel.app/>**

アカウントもアプリも要りません。URLを開くだけで遊べます。

Three.js（ローカルに同梱）＋バニラ JS。ビルド不要、画像・音声ファイルなし
（形状はすべてコード生成、効果音はすべて WebAudio 合成）。

> 開発するとき（人もAIも）は **[AGENTS.md](AGENTS.md)** を先に読んでください。

## 操作

### パソコン

| キー | 動作 |
|---|---|
| WASD | 移動 |
| マウス | 視点 |
| Shift | ダッシュ（スタミナ消費） |
| Space / C | 浮く・沈む（そとでは 屋根のずっと上、32mまで） |
| E | おどかす（背後からは1.75倍。あまのじゃくは2.5倍） |
| Q | すりぬけ（壁を通る／人間から見えにくくなる） |
| Tab | おばけ工房（仕掛け・おばけ・交換所） |
| F | 選んだ仕掛けを置く |
| R | 置いた仕掛け・おばけを回収する |
| 1〜9 / 0 / ホイール | 仕掛けを選ぶ |
| Esc | ポーズ（セーブ・ホーム・ともだち） |

### スマホ・タブレット（横向き）

左下のスティックで移動（端まで倒すとダッシュ）、画面をなぞって視点。
右下のボタンで おどかす／すりぬけ／うく／おく／もどす／おばけ工房。

端末を判定して自動で切り替わります。スマホでは光源や草の量を落として軽くしています。

## 遊びかた

### ステージ

- 夕暮れ木造校舎：はじめから遊べます
- 霧ヶ丘分校：追い出した人間が1000人を超えると解放されます
- 月影廃遊園地：追い出した人間が2000人を超えると解放されます

開始画面でステージを選びます。マップは選んだ1つだけを読み込むため、
ほかのステージを追加しても3マップ分が同時に動くことはありません。

1. 材料（光るカケラ）を拾う。近づけば自動で拾えます
2. **Tab** で「おばけ工房」を開き、仕掛けを作る／おばけを呼ぶ
3. **F** で仕掛けを置き、**E** で人間をおどかす
4. 怖がりきった人間は、自分が入ってきた門から逃げていきます
5. 追い出した人数でランクが上がり、強いおばけが解放されます

### アイテムの色＝値うち

**白 → 水色 → 青 → 赤 → 紫 → 銀 → 金** の7段階。
色が濃いほど一度にたくさん手に入ります（白1個 → 金25個）。

**ふつうは行かない場所ほど、いい色が落ちています。**
運動場の四すみ、屋上、体育館の裏、4階、そして「すりぬけ」でしか行けない秘密の教室。
金は普通の場所で 0.01%、秘密の教室で 1.7%。

白より上を拾うと「かけら」が貯まり、**交換所**で仕掛け・おばけ・**すがた**と交換できます。

### すがたを きたえる

すがたを手に入れたあとは、**おばけ工房 →「すがたを きたえる」**で強化できます。
**はやさ・ダッシュ・こわさ・とどく・すりぬけ**を、すがたごとに **Lv30**まで。
1レベルで ×0.02 ずつ上がるので、カンストすると +0.60。
材料と「かけら」を使い、上げるほど良い色のかけらが必要になります。

### すがた（あやつるキャラ）

| すがた | とくい |
|---|---|
| 👻 しろいおばけ | はじめから使える。バランス型 |
| 👁 一つ目小僧 | とどく範囲が広い |
| 🌂 唐傘おばけ | すりぬけが長もち |
| 😈 あまのじゃく | ふいうちが2.5倍 |
| 🥒 河童 | 足が速い |
| 🍃 天狗 | とどく範囲1.45倍 |
| 🦊 九尾 | すべて最強 |

## いま入っているもの

**マップ**
4階建ての木造校舎（教室・理科室・音楽室・家庭科室・職員室・男女トイレ・図書室）
＋ 屋上 ＋ 中庭 ＋ 渡り廊下 ＋ 部室棟 ＋ 運動場 ＋ 体育館 ＋
**すりぬけでしか行けない秘密の教室**。
まわりは針葉樹林と山。出入口は4か所（正門・東の通用門・西の裏門・北の勝手口）。

**人間**
性格18種、指名キャラ84人、名まえ184種（たまひよ2025年の読みランキング＋昔ふう）。
100グループが順番に来て、一周するまで同じ組は来ません。
**時間がたつほど どんどん来ます**（マップには最大15人）。
右の名まえを**押すと、その人をさがせます**。光の柱が立ち、
画面の下に「どっちの向き・何メートル・何階」が出ます。
名前に合った服装（ジャージ／エプロン／スーツ／作務衣／警察の制服など）。
探索 → びくびく → パニック → 逃走 → 脱出。同じ手を繰り返すと**慣れて笑われ**、
別の手を続けざまに出すと「たたみかけ」ボーナス。

**作れるもの**
仕掛け12種（ツルツルトラップ、校内放送ジャック、はがれたお札 …）／
召喚おばけ7種（くびなし体操服、かげろう先生、巨大てるてる坊主 …）／材料9種

**ともだちと遊ぶ**
あいことば4文字の部屋で最大4人。**同じ廃校・同じ人間・同じ拾いもの**を全員が見ます。
だれかが拾うと全員の画面から消え、材料は**全員がもらえます**（取りあいなし）。
置いた仕掛け・召喚おばけも、おたがいの画面に出ます。
「ともだち」タブから、あいことばで入る／ともだち全員をいっぺんにさそう、ができます。
**おどかし勝負**もできます。3・2・1のあと、決めた時間（1／3／5分）で
どれだけ多くおどかせたかを競い、けっか発表でごほうびがもらえます。
人間を**はさみうち**にすると、こわさ2.1倍＋いい色の材料がどっさり。
だれかがおどかすと、**その場の全員が材料を1つもらえます**（取りあいなし）。
ログインすると「ともだち」機能（申請・プロフィール・さそい）も使えます。

**隠し要素**
赤いワンピースの女の子、どこかのトイレのうんこ、運動場のネコ、体育館裏の告白。

## 開発

```bash
node serve.js          # http://localhost:5178
```

ビルド不要。ログイン・ともだち・部屋は Vercel Blob が要るので、
ローカルでは動きません（公開URLで確認してください）。

```bash
node tools/nettest.mjs    # 部屋のやりとりを本番に対してテスト
node tools/frtest.mjs     # ともだち機能をテスト
```

くわしくは **[AGENTS.md](AGENTS.md)** と [SETUP-CLOUD.md](SETUP-CLOUD.md) を見てください。

## 応援について

このゲームは**これからもすべて無料**です。
ホーム画面の「☕ このゲームを応援する」は、大人向けの**まったくの任意の寄付**で、
押してもゲームの内容は一切変わりません。

支払いは Stripe の画面だけで行われ、このゲームはカード番号を受け取りません。
